# Eye Disease Classification Using Deep Learning

## About the Project

This project explores how deep learning can be used to classify common eye diseases from external eye images.

The project uses the Mendeley Eye Disease Dataset, which contains five categories: Normal, Cataract, Conjunctivitis, Uveitis and Eyelid Drooping.

The main aim is to train and compare different deep learning models and identify which model performs best for this classification task.

## Models Used

* Baseline CNN
* VGG16
* ResNet50
* InceptionV3
* Hybrid Vision Transformer (ViT)

## Dataset

The dataset used in this project is the publicly available Mendeley Eye Disease Dataset.

Dataset link:
https://data.mendeley.com/datasets/n9zp473wfw/1

The dataset itself is not included in this repository.

## What is Included

The main Jupyter Notebook contains the complete project work, including:

* Dataset loading and exploration
* Image preprocessing
* Data augmentation
* Model training
* Transfer learning and fine-tuning
* Model evaluation
* Accuracy, precision, recall and F1-score
* Confusion matrices
* ROC-AUC analysis
* Comparison of the different models
* Eye disease prediction using a Gradio interface

## Results

ResNet50 achieved the best overall performance, with a test accuracy of 94.20% and a macro F1-score of 0.9240.

The complete results, graphs and outputs are available in the Jupyter Notebook.
